# AGENTS.md

**Eäsis** — a Quenya self-study app (Kotlin Multiplatform + Compose Multiplatform). Read
[README.md](README.md) first for what's built and verified, [BACKLOG.md](BACKLOG.md) for
prioritized open work, [SPEC.md](SPEC.md) for the full design.

## Build and test

Always use the committed wrapper (`./gradlew ...`), never a bare `gradle` — see README.md's
"Run the logic tests" and "Build the Android app" sections for the exact commands.

## Generated data

Everything under `composeApp/.../composeResources/files/*.json` (lexicon, forms, phrases, lesson
text, lesson order) is generated by `tools/build_data.py` from Eldamo's data, not hand-authored.
Change `tools/skeleton.json` or the script and regenerate — never hand-edit the JSON.

## Commits

Commit messages are the user's own words alone. Do not add a `Co-Authored-By`, "Generated with",
or similar self-attribution trailer naming an AI tool. A `commit-msg` hook enforces this and
rejects commits that violate it — if yours is rejected, strip the trailer and recommit; don't
bypass the hook.

One-time setup per clone: `git config core.hooksPath .githooks`.
